# Nimú — Architecture

Static vanilla storefront (dietética). No framework, no build, no `package.json`.

## Stack

| Layer | What |
|-------|------|
| Frontend | `index.html` + `styles.css` (all UI/state/fetch/cart) |
| Catalog | Static JSON under `data/` (GitHub Pages) |
| Source of truth | Google Sheets (1 spreadsheet per place) |
| Backend | Google Apps Script (`resources/*.js` → copy into GAS editor) |
| Checkout | WhatsApp (`wa.me`) + background order POST to Sheets |

Local preview needs an HTTP server (`python3 -m http.server 8000`). `file://` breaks `fetch('data/...')`.

## Repo map

```
index.html                 # Entire app
styles.css
data/
  places.json              # [{id,name}] — only file always in clone
  {placeId}/categories.json          # generated by publisher
  {placeId}/products/{slug}.json     # generated by publisher
resources/
  appscript.js             # Catalog API + CacheService + legacy doPost
  appscript-publish.js     # Sheets → GitHub JSON (time trigger ~15 min)
  appscript-pedidos.js     # Active order writer (ORDERS_URL)
```

`imgs/` and most of `data/{place}/` may be missing locally until publisher runs / Pages deploy.

## Data flow

```
Google Sheets (tabs = categories)
        │
        ├─ publishCatalog() ~15min ──► GitHub data/*.json ──► fetch() ──► UI
        │
        └─ doGet ?action=search ─────► APPS_SCRIPT_URL ──► global search

Cart → WhatsApp (primary UX)
     └─ form POST orderData (iframe) → ORDERS_URL
            ├─ findOrCreateClientCode_ → Contacts sheet (DB CONTACTS SF/BA)
            └─ append order rows (con CodCliente) → Orders spreadsheet
```

### Sheet schema

- Tabs = categories; tabs starting with `_` ignored.
- Columns: `id`, `name`, `imageUrl`, `description`, `variants`
- Cover row: `id=_cover` or `name=categoryimage` (not a product)
- `variants`: JSON array `[{label, price, code}]`

## Apps Script (`resources/`)

Source in repo is **not** auto-deployed. Edit in Google, keep `resources/` in sync.

### A — `appscript.js` (catalog API)

`doGet` actions: `places` | `categories` | `products` | `search` | legacy `grouped=true`.

Server cache: `CacheService`, **TTL 300s**.

Keys: `categories_v1_{place}`, `products_v1_{place}_{category}`, `search_v1_{place}_{q}`, `catalog_v3_{place}_g`.

`doPost` here is **legacy** (writes into each place’s catalog sheet). Frontend does **not** use it.

### B — `appscript-pedidos.js` (orders)

Active writer for `ORDERS_URL`. `doPost` reads `e.parameter.orderData`, returns HTML that `postMessage`s to parent.

On each order:
1. `findOrCreateClientCode_(place, customer)` — match phone (normalized digits) then name; else append next `S#`/`B#` in contacts tab.
2. Write order rows with **CodCliente** after Fecha.

Order columns: `Fecha y Hora`, `CodCliente`, `Nombre`, `DNI`, `Teléfono`, `Dirección`, `Zona`, `Lugar`, `Notas`, `Detalle Producto`, `Codigo Producto`, `Cantidad`.

**Deploy (manual):** insert column `CodCliente` after Fecha in existing order tabs → paste updated script into GAS project → ensure edit access to contacts sheet → redeploy Web App version (keep `ORDERS_URL` if updating same deployment).

### C — `appscript-publish.js` (static publisher)

Same GAS project as A. `publishCatalog()` → GitHub Contents API.

Script properties: `GITHUB_TOKEN`, `GITHUB_REPO` (default `pablojorgeandres/tienda-nimu`), `GITHUB_BRANCH` (default `main`).

Writes: `data/places.json`, `data/{place}/categories.json`, `data/{place}/products/{slug}.json`.

## Cache (faster loads)

### Browser `localStorage` — 24h

`CACHE_EXPIRY_MS = 24h`. Helpers: `setCacheWithExpiry` / `getCacheWithExpiry`.

| Key | Content |
|-----|---------|
| `categories_v2__{placeId}` | categories object |
| `products_v2__{placeId}__{category}` | product array |

`clearCache()` removes keys starting with `categories_`, `products_`, `catalog_`.

Other LS (not catalog TTL): `cart`, `deliveryZone__{placeId}`, `nim_cart_important_*`.

Search is **not** cached client-side.

### Apps Script `CacheService` — 5 min

Used for live `doGet` (mainly search today). Independent key versioning (`v1` server vs `v2__` client).

### Static JSON on GitHub

Implicit CDN. Publisher ~15 min. Client 24h cache can hide fresher publishes until expiry / `clearCache()` / key bump.

### Images

Drive URLs normalized to thumbnails; lazy backgrounds via `IntersectionObserver` (`LAZY_BG_ROOT_MARGIN = 150px`).

## Views / state


## Gotchas

1. README is partly outdated (`PRODUCTS_URL` / PWA / open without server — ignore).
2. Frontend orders go **only** to `ORDERS_URL` (`appscript-pedidos.js`), not catalog `doPost`.
3. Incomplete local clone: missing generated JSON / `imgs/` is normal.
4. Category tab names are case-sensitive; slug is filename only.
5. WhatsApp is primary; sheet save is best-effort (`console.warn` on fail).
6. No service worker / PWA despite older README claims.
7. Bump cache key version (`v2` → `v3`) to force clients to refetch after breaking catalog changes.
